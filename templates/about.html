About This System
Automatic Number Plate Recognition — Nepali Embossed Plates

📌 Project Overview

This system is a college-level final year project implementing an Automatic Number Plate Recognition (ANPR) system specifically designed for Nepali embossed number plates. The system detects vehicle number plates, recognizes characters, and matches against a watchlist to trigger alerts.

The core character recognition CNN is implemented entirely from scratch using NumPy — without any pre-built deep learning libraries — achieving 98.6% test accuracy on the Nepali embossed plate character dataset.

Initial Development Phase — Privacy Notice
This system is currently in its initial development phase and is intended for academic and demonstration purposes only. All vehicle detections are stored locally and not shared with third parties. The system should not be used for actual law enforcement without proper legal authorization. By using this system, you acknowledge it is a student project under active development.
