System Features
Everything needed for vehicle surveillance and watchlist management
🧠
CNN From Scratch
Character recognition implemented entirely in NumPy without any deep learning frameworks. Convolution, pooling, backpropagation all custom built.
🎯
Dual YOLO Detection
Two fine-tuned YOLOv8s models. First detects plate regions, second detects individual character bounding boxes within the plate.
🚨
Real-Time Alerts
Instant dashboard popup, audible alert sound, and official HTML email with detection image dispatched to all registered authorities.
📹
Multiple Input Modes
Supports image upload, video file upload with annotated output video generation, and live webcam stream detection.
📋
Watchlist Management
Full CRUD operations for managing watchlisted vehicles. Add owner details, reason for flagging, and track all detection history.
🔐
Secure Access Control
Role-based authentication with Admin and User roles. SHA-256 password hashing. All routes protected by login decorator.
📊
Detection Logging
Every detection logged with plate text, confidence, timestamp, annotated image, and source. Export all logs as CSV for reporting.
📧
Authority Notification
Register multiple authority email addresses. Official alert emails with detection images automatically dispatched via Gmail SMTP.
🔍
Processing Visualization
Dashboard shows all four preprocessing steps: grayscale, CLAHE enhancement, thresholding, and character detection bounding boxes.
